# 🛡️ PhishShield - AI Phishing Email Detector

A powerful machine learning-based phishing email detection system using Random Forest Classifier.

## Features
- ✅ Machine Learning detection (Random Forest)
- ✅ Real-time email analysis
- ✅ 96%+ accuracy
- ✅ URL and keyword detection
- ✅ Beautiful web interface
- ✅ CLI testing mode

## Tech Stack
- **Backend:** Python, Flask, Scikit-learn
- **Frontend:** HTML5, CSS3, JavaScript
- **ML Algorithm:** Random Forest Classifier
- **Features:** TF-IDF + Handcrafted features
